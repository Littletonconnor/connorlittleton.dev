Tools I actually use daily for software development.

## Editor

**[Cursor](https://cursor.com)** — VS Code fork with AI built in. I use Claude as the model. The tab completion and inline edits are genuinely useful, not just gimmicks.

**[IntelliJ IDEA](https://www.jetbrains.com/idea/)** — For Java/Kotlin work. Nothing else comes close for JVM languages.

## Terminal

**[Ghostty](https://ghostty.org)** — Fast, native macOS terminal. Written in Zig. I use:

- Catppuccin Macchiato theme
- Dank Mono font at 18px
- Native splits instead of tmux panes

**[Starship](https://starship.rs)** — Minimal prompt. Just directory, git branch, and a rocket emoji. I disable all the language version indicators—they're noise.

**[tmux](https://github.com/tmux/tmux)** — Session persistence. Mainly for keeping long-running processes alive.

## CLI Tools

- **[fzf](https://github.com/junegunn/fzf)** — Fuzzy finder for everything. Files, history, git branches.
- **[ripgrep](https://github.com/BurntSushi/ripgrep)** — grep replacement. 10x faster, respects .gitignore.
- **[fd](https://github.com/sharkdp/fd)** — find replacement. Sane defaults, faster.
- **[eza](https://github.com/eza-community/eza)** — ls replacement. Colors, git status, tree view.
- **[bat](https://github.com/sharkdp/bat)** — cat replacement. Syntax highlighting, git integration.
- **[zoxide](https://github.com/ajeetdsouza/zoxide)** — cd replacement. Jumps to frecent directories.
- **[lazygit](https://github.com/jesseduffield/lazygit)** — Terminal UI for git. Faster than typing commands for complex operations.
- **[jq](https://github.com/jqlang/jq)** — JSON processor. Indispensable for API work.
- **[tldr](https://github.com/tldr-pages/tldr)** — Practical command examples instead of man pages.
- **[htop](https://github.com/htop-dev/htop)** — Process viewer that doesn't suck.

## Browser

**Chrome** — DevTools are still the best.

## Productivity

**[Raycast](https://raycast.com)** — Spotlight replacement. I use it for:

- Clipboard history
- Window management
- Quick calculations
- App launching

**[CleanShot X](https://cleanshot.com)** — Screenshots and screen recording. The annotation tools are excellent.

**[1Password](https://1password.com)** — Password manager. The CLI integration is useful for scripts.

## Design

**[Figma](https://figma.com)** — Design tool. I use it for mocking up UIs before building.

## Containers

**[Rancher Desktop](https://rancherdesktop.io)** — Docker Desktop alternative. Free, open source, less resource-hungry.

## Hardware

**[Logitech MX Master 4](https://www.logitech.com/en-us/products/mice/)** — Best mouse for productivity.

## Fonts

**[Dank Mono](https://philpl.gumroad.com/l/dank-mono)** — Paid, but worth it. The italics are beautiful and actually make code more readable.
